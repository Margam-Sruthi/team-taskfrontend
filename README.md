- React (Vite)
- Tailwind CSS

## Backend API
https://team-taskbackend-production.up.railway.app

## Setup
1. Clone repo
2. Install dependencies:
   npm install
3. Add .env file:
   VITE_API_URL=https://team-taskbackend-production.up.railway.app
4. Run app:
   npm run dev
